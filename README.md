# PATRA Language

PATRA is a multilingual programming language and development environment.

## Initial architecture

- `Patra.Core`: language foundations and shared models.
- `Patra.Compiler`: compiler command-line application.
- `Patra.Studio`: Windows desktop development environment.
- `Patra.Tests`: automated tests.
- `examples`: sample PATRA programs.
- `docs`: language and architecture documentation.

## Status

Initial project foundation. Language features are implemented incrementally and verified through tests.

## Requirements

- .NET 8 SDK or a compatible SDK with the .NET 8 targeting packs.
- Windows for the WinForms development environment.
